# Atoms Public Product Experience

体验日期：2026-08-09；范围为无需账号即可访问的公开首页和登录入口。

- 首页第一屏以一句话输入框作为主入口，并提供 SaaS、电子商务、内部工具、个人项目等模板分类。
- 首页强调八个具名 Agent 的专业分工，并把用户定位为决策者、Agent 定位为研究、规划、构建、测试和增长的执行团队。
- 产品价值表达从“生成代码”扩展到“把想法变成可销售产品”，同时强调真实应用、后端、发布和增长。
- 登录入口支持 Google 或邮箱，未输入邮箱时继续按钮保持禁用。
- 未使用个人账号继续登录，因此工作区内部行为仍以官方帮助资料为准。

## 设计辅助结论

- Demo 第一屏应直接让用户输入想法，而不是先解释技术架构。
- 模板示例可以降低空白输入压力，但生成后应快速把视觉焦点交给可操作的应用预览。
- Agent 角色应有明确职责和阶段产出，避免只有头像装饰。
