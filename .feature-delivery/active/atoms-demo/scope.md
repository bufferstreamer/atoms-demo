# Atoms AI App Builder Demo - 范围与能力边界

## 业务目标

构建一个可在线访问的 AI 应用生成工作区。用户输入自然语言需求后，多个可见 Agent 依次完成理解、规划、设计和构建，最终在同一页面生成可交互应用，并支持保存和继续迭代。

## 当前现状

当前仓库只有 Sites 空项目骨架，没有业务功能。MGX/Atoms 官方主流程和挑战要求已完成第一轮取证，见 `facts.md`。

## 本期范围

- 新用户免注册初始化与引导演示。
- 新建项目、输入需求、触发多 Agent 生成。
- 生成结果在预览区真实可操作。
- 项目、消息、Agent 状态和版本持久化。
- 继续修改生成结果，并在版本之间切换。
- 在线部署、分享链接和真实浏览器验收。

## 明确不做

- 不调用外部收费大模型，不承诺生成任意代码。
- 不提供真实 GitHub、Stripe、Supabase 或广告投放集成。
- 不提供多人协作、复杂权限和企业 SSO。
- 不生成原生移动端应用。

## 兼容与无感升级

新建 Demo，无存量用户或接口兼容要求。数据库 schema 变更必须可重新初始化；发布失败时可回滚到上一可用构建。
