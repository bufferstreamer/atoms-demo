# Atoms Demo Challenge Brief

来源：用户于 2026-08-09 提供的挑战要求。

- 先阅读 `https://support.mgx.dev/en`，再结合实际体验设计并实现应用。
- 实现一个可运行的网页应用，具备类似 Atoms 的能力与 UI 交互体验。
- 用户通过智能体驱动的方式完成代码或应用生成，并以可视化网页展示生成结果。
- Demo 必须具备真实交互，不能是纯静态展示。
- Demo 必须具备数据持久化。
- 在资源允许时覆盖初始化或注册、核心主流程，以及至少一个延展能力。
- 最终必须提供可测试的在线访问链接和实际可用功能，不能只有概念验证。

## 正式评估维度

- 完成度：功能完整性、稳定性与基本工程质量。
- 工程思维：任务拆解、技术选型、复杂度控制与取舍能力。
- 用户体验：交互是否清晰、流程是否顺畅、是否可用。
- 创新性：是否有亮点设计、独特视角或可扩展潜力。
- 可交付性：文档清晰度、可运行程度、整体完成质量。
