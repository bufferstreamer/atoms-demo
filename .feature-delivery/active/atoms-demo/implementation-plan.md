## 4. 开发与联调顺序

1. 新建项目并生成首个可交互版本。
2. 刷新恢复项目与版本。
3. 验证幂等、同项目串行、超时 run 恢复、owner 隔离和容量边界。
4. 继续修改、乐观激活并切换历史版本。
5. 失败保护、窄屏和在线验收。

## 5. 发布与回滚顺序

迁移 D1 → 构建 → 部署 → 在线冒烟。失败时回滚应用版本；新增 schema 保留，不做破坏性清理。
